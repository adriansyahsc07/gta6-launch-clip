A 25-second vertical GTA 6 clip, found, cut and rendered by an AI agent with ffmpeg: a five-star pickup rampage down Vice Ocean Beach ends with the truck launched clean over a wrecked car and into the parked trucks, then the clip turns to the viewer and pitches make.fun — make clips like this with AI and earn money. The clip is published as a public YouTube Short; `VIDEO.json` names its address, and `main.ts` hands that address to the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
